## 两家到底是什么定位

一句话概括：搬瓦工卖线路，RackNerd 卖配置。

搬瓦工的招牌是 CN2 GIA。这条线是电信的精品承载网，去程回程都走 GIA 通道，绕开拥堵节点；CN2 GIA-E 是它的电商级增强版，三网各有专门回程——电信走 CN2 GIA（AS4809），移动走 CMIN2（AS58807），联通走 China Unicom Premium（AS10099）。它自研的 KiwiVM 面板支持开关机、重装、迁机房、快照，自动备份免费送，15+ 机房可以一键免费切换，换机房不丢数据、不用重装系统。

RackNerd 背靠 QuadraNet 老牌机房资源，走的是量大管饱路线：21 个数据中心分布在北美、欧洲、亚洲 20 个地点，KVM 虚拟化、RAID-10 纯 SSD、1Gbps 端口，默认带 DDoS 防护，每个套餐给一个专属 IPv4 和完整 root 权限。它的短板也明确：控制面板是基础款的 SolusVM，没有自动备份和快照，机房买下后一般不能换，线路没有任何中国优化。

还有一个常被忽略的差异：付款和兜底。搬瓦工支持支付宝、银联、PayPal、信用卡，新账户 30 天内可以退款（条件是流量使用不超过 10%、IP 没被封）；RackNerd 支持支付宝、PayPal、信用卡，但促销套餐一般不退款。也就是说，买搬瓦工试错成本是 30 天，买 RackNerd 基本是一锤子买卖。
